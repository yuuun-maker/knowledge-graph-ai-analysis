##4.2 if-else 语句（If-else statements）


21. 给定以下内容，哪部分是条件？
    ```python
    if age < 12:
        print("Discount for children available")
    ```
    a. age
    b. age < 12
    c. print("Discount for children available")
22. 给定以下内容，如果条件为真，哪些行执行？
    ```python
    1  print("Have a great day.")
    2  if is_raining:
    3      print("Don't forget an umbrella!")
    4  print("See you soon.")
    ```
    a. 1, 2, 3
    b. 1, 2, 4
    c. 1, 2, 3, 4
23. 给定以下内容（同上），如果条件为假，哪些行执行？
    a. 1, 2, 3

    b. 1, 2, 4
    c. 1, 2, 3, 4
24. 给定 num = -10，num 的最终值是什么？
    ```python
    if num < 0:
        num = 25
    if num < 100:
        num = 75
    ```
    a. -10
    b. 25
    c. 75
25. 给定输入 10，positive_num 的最终值是什么？
    ```python
    positive_num = int(input("Enter a positive number:"))
    if positive_num < 0:
        print("Negative input set to 0")
    positive_num = 0
    ```
    a. 10
    b. 0
    c. Error
26. 给定以下代码，对于哪个范围的 x，采用 else 分支？
    ```python
    if x >= 15:
        # ...
    else:
        # ...
    ```
    a. x < 15
    b. x >= 15
    c. x > 15
27. 给定 x = 40，y 的最终值是什么？
    ```python
    if x > 30:
        y = x - 10
    else:
        y = x + 10
    ```
    a. 30
    b. 40
    c. 50
28. 给定 y = 50，哪个不是 y 的可能最终值？
    ```python
    if x < 50:
        y = y / 2
    else:
        y = y * 2
    y = y + 5
    ```
    a. 30
    b. 55
    c. 105

##4.5 链式决策（Chained decisions）


48. 填空，使 condition_1 为假且 condition_2 为真时执行 Body 2。
    ```python
    if condition_1:
        # Body 1
    ______ condition_2:
        # Body 2
    ```
    a. if
    b. elif
    c. else
49. 给定 x = 42 和 y = 0，y 的最终值是什么？
    ```python
    if x > 44:
        y += 2
    elif x < 50:
        y += 5
    ```
    a. 2
    b. 5
    c. 7
50. 哪些条件完成代码，使得如果 x 小于 0，执行 Body 1，否则如果 x 等于 0，执行 Body 2。
    ```python
    if ______:
        # Body 1
    elif ______:
        # Body 2
    ```
    a. x < 0、x == 0
    b. x == 0、x < 0
    c. x <= 0、[无条件]
51. 以下哪项是有效的链式决策语句？
    a. if condition_1: # Body 1 elif condition_2:
    b. if condition_1: # Body 1 elif condition_2: # Body 2
    c. elif condition_1: # Body 1 if condition_2: # Body 2
52. 给定 attendees = 350，rooms 的最终值是什么？
    ```python
    rooms = 1
    if attendees >= 100:
        rooms += 3
    if attendees <= 200:
        rooms += 7
    elif attendees <= 400:
        rooms += 14
    ```
    a. 4
    b. 15
    c. 18
53. 给定 hour = 12，打印什么？
    ```python
    if hour < 8:
        print("Too early")
    elif hour < 12:
        print("Good morning")
    elif hour < 13:
        print("Lunchtime")
    ```
    a. Too early
    b. Good morning
    c. Lunchtime
54. 在哪里可以添加 elif 语句？
    ```python
    1  if condition:
    2      # Body
    3  elif condition:
    4      # Body
    5  else:
    6      # Body
    ```
    a. 1
    b. 2
    c. 3
    d. 4
55. 给定 x = -1 和 y = -2，y 的最终值是什么？
    ```python
    if x < 0 and y < 0:
        y = 10
    elif x < 0 and y > 0:
        y = 20
    else:
        y = 30
    ```
    a. 10
    b. 20
    c. 30
56. 以下语句如何重写为链式语句？
    ```python
    if price < 9.99:
        order = 50
    if 9.99 <= price < 19.99:
        order = 30
    if price >= 19.99:
        order = 10
    ```
    a. if price < 9.99: order = 50 else: order = 30 order = 10
    b. if price < 9.99: order = 50 elif price < 19.99: order = 30 elif price == 19.99: order = 10
    c. if price < 9.99: order = 50 elif price < 19.99: order = 30 else: order = 10

57. 考虑上面的示例。给定 leaf_count = 9 和 leaf_shape = "teardrop"，输出是什么？

58. 给定 num_dancers = 49，打印什么？
    ```python
    if num_dancers < 0:
        print("Error: num_dancers is negative")
    else:
        if num_dancers % 2 == 1:
            print("Error: num_dancers is odd")
        print(num_dancers, "dancers")
    ```
    a. Error: num_dancers is odd
    b. 49 dancers
    c. Error: num_dancers is odd 49 dancers

    ```python
            # Body 3
        else:
            # Body 4
    ```
    a. Body 2

##4.7 条件表达式（Conditional expressions）

61. 以下 if-else 语句的条件表达式版本是什么？
    ```python
    if x % 2 == 0:
        response = 'even'
    else:
        response = 'odd'
    ```
    a. response = if x % 2 == 0 "even" else "odd"
    b. response = "odd" if x % 2 == 0 else "even"
    c. response = "even" if x % 2 == 0 else "odd"
62. 给定 x = 100 和 offset = 10，result 的值是什么？
    ```python
    result = x + offset if x < 100 else x - offset
    ```
    a. 90
    b. 100
    c. 110
63. 条件表达式的哪部分不正确？
    ```python
    min_num = x if x < y else min_num = y
    ```
    a. min_num = x
    b. x < y
    c. min_num = y
64. 以下 if-else 语句的改进版本是哪个？
    ```python
    if x < 50:
        result = True
    else:
        result = False
    ```
    a. result = True if x < 50 else False
    b. result = x < 50
65. total 的可能值是什么？
    ```python
    total = fee + 10 if hours > 12 else 2
    ```
    a. 10, 2
    b. fee + 10, 2
    c. fee + 10, fee + 2
