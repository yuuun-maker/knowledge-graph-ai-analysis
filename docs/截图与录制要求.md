# 截图与录制要求（内部工作稿，不随作品提交）

> 这份文件是**写给团队自己看的**，用于补齐《图谱构建示例》所需的 8 张截图。
> 它不进入提交包——提交材料里只保留正文与图，不保留"待办清单"。

## 一、怎么用

把下表列出的 8 张图片按文件名放进 `docs/` 目录（与 `图谱构建示例.tex` 同级），
`\shot` 命令会自动把占位框替换为图片，**正文一个字都不用改**。

命名必须完全一致，扩展名统一为 `.png`。

## 三、脱敏要求（违规红线）

参赛指南的原创承诺要求：提交的文字与视频作品中**不得出现参赛学校名称和指导教师姓名**，
及其提示、图片、照片、图像或链接等形式的暗示内容。

拍摄前逐项检查，以下位置最容易漏：

- 浏览器**书签栏**、标签页标题、历史记录下拉
- 系统**账号昵称 / 头像**、页面右上角用户名
- **文件路径**与桌面文件名（截图里若露出资源管理器地址栏要遮挡）
- 编辑器窗口标题栏（含用户名或项目路径）
- 输出了 `C:\Users\真实姓名\...` 的终端窗口

建议做法：用干净的演示账号，浏览器开**全屏演示/无痕窗口**，把书签栏关掉。

## 四、配套的两处正文口径

拍摄时请让画面与正文说的一致，否则图文对不上：

1. 第 5 章的"修正前"图要能看出三类问题：**「满二叉树」是孤立节点**、
   缺 **「平衡二叉搜索树 CONTAINS 红黑树」**、
   以及 **「初始化二叉树」「构建二叉搜索树」两个误抽节点**；
2. 第 4 章统计表写的是**第 1 轮**结果（52 知识点 / 40 关系），
   截图谱全景时请确认取的是同一轮的数据，不要取第 2、3 轮。
