##索引

##Unicode

Python 使用 Unicode，这是计算机上表示文本的国际标准。Unicode 为每个可能的字符定义了一个唯一的数字，称为码点。例如："P" 的码点是 80，"!" 的码点是 33。

内置的 ord() 函数将字符转换为码点。例如：ord("P") 返回整数 80。类似地，内置的 chr() 函数将码点转换为字符。例如：chr(33) 返回字符串 "!"。Unicode 是 ASCII（美国信息交换标准代码）的扩展。最初，ASCII 只定义了 128 个码点，足以支持英语。Unicode 定义了超过一百万个码点。

移位密码

在罗马帝国时期，Julius Caesar（公元前 100-44 年）使用一种简单的技术来加密私人信息。消息的每个字母都被替换为字母表中后面的第三个字母。例如：如果消息是 CAT，C 变成 F，A 变成 D，T 变成 W，结果是消息 FDW。这种技术称为移位密码，因为每个字母都移位了某个量。在 Caesar 的情况下，量是三，但其他量（除了 0）也可以。

编写一个程序，提示用户输入以下两个值（示例输入以粗体显示）：

```
Enter a 3-letter word: CAT
Shift by how many letters? 3
```

然后程序应将单词的每个字母移位所需的量。基于上面的示例，输出将是：

```
The secret message is: FDW
```

提示：使用 ord() 函数将每个字母转换为整数，将移位量加到每个整数，使用 chr() 函数将每个整数转换为字符，并连接结果字符。

##F-string

格式化字符串字面量（或 f-string）是以 "f" 或 "F" 为前缀的字符串字面量。替换字段是 f-string 中花括号（{}）内的表达式。例如：字符串 f"Good morning, {first} {last}!" 有两个替换字段：一个用于名字，一个用于姓氏。F-string 提供了一种方便的方法将多个值组合成一个字符串。

##格式化数字

程序经常需要以特定格式显示数字。例如：显示时间时，分钟格式化为两位整数。如果小时是 9，分钟是 5，那么时间是 "9:05"（不是 "9:5"）。

在 f-string 中，替换字段可以包含由冒号引入的格式说明符。格式说明符定义值应如何格式化以显示。例如：在字符串 f"{hour}:{minute:02d}" 中，minute 的格式说明符是 02d。

表 3.3 示例格式说明符

##对象的属性

每个对象都有一个身份、一个类型和一个值：

· 对象的身份是与该对象关联的唯一整数。通常，这个整数指对象存储的内存位置。一旦创建，对象的身份永远不会改变。内置的 id() 函数返回对象的身份。
· 对象的类型决定对象的可能值和操作。例如：整数和浮点数可以使用 / 运算符"相除"，但字符串不能。内置的 type() 函数返回对象的类型。
· 对象的值表示对象的当前状态。许多对象，如数字和字符串，一旦创建就无法修改。一些对象，如列表（稍后介绍），设计为可修改。

##EXPLORING FURTHER

如内存图所示，变量和对象是两个独立的概念。调用 id() 或 type() 等函数返回关于对象的信息，而不是关于变量的信息。事实上，变量没有身份或类型，如下例所示：

```python
>>> rating = 10  # 内存中某处的整数对象。
>>> type(rating)
<class 'int'>
>>> id(rating)
9793344
>>> rating = "ten"  # 内存中另一处的字符串对象。
>>> type(rating)
<class 'str'>
>>> id(rating)
140690967388272
```

有人可能错误地认为 rating 变量的类型或身份发生了变化。然而，唯一改变的是 rating 变量引用的对象。

##3.4 列表基础（List basics）

##列表

列表对象可用于在 Python 中将元素捆绑在一起。列表通过使用方括号 [] 和方括号内逗号分隔的值来定义。例如：list_1 = [1, 2, 4]。

空列表可以通过两种方式定义：

```python
list_1 = []
list_1 = list()
```

列表可以由任何类型的元素组成。列表可以包含整数、字符串、浮点数或任何其他类型。列表也可以包含类型的组合。例如：[2, "Hello", 2.5] 是有效列表。

Python 列表允许程序员以各种方式更改列表的内容。

##使用索引

单个列表元素可以使用索引直接访问。索引从 0 开始，到序列长度减一结束。例如：对于 50 个元素的序列，第一个位置是 0，最后一个位置是 49。

索引号放在方括号 [] 中，并附加到列表名称的末尾以访问所需元素。例如：new_list[3] 访问 new_list 中的第 4 个元素。求值为整数的表达式也可以用作索引。与字符串类似，负索引也可用于寻址单个元素。例如：索引 -1 指最后一个元素，-2 指倒数第二个元素。

len() 函数在作用于列表时返回列表的长度。

##创建元组和访问元素

元组是逗号分隔的值的序列，可以包含不同类型的元素。元组必须用值之间的逗号创建，按照惯例，序列用括号括起。每个元素通过索引访问，从第一个元素在索引 0 开始。

表 3.4 示例元组

```python
tuple_1 = (2, 3, 4)
print(f'tuple_1: {tuple_1}')
print(tuple_1[1])
print()
data_13 = ('Aimee Perry', 96, [94, 100, 97, 93])
print(f'data_13: {data_13}')
print(data_13[2])
```

输出：

```
tuple_1: (2, 3, 4)
3

data_13: ('Aimee Perry', 96, [94, 100, 97, 93])
[94, 100, 97, 93]
```

##可变性和性能

元组是不可变的且大小固定，因此元组使用更少的内存。总体而言，元组创建和访问更快，从而带来更好的性能，在处理大量数据时可能很明显。

· 字符串是表示 Unicode 码点的值序列。

· 元组类似于列表，但使用括号，且创建后无法更改。
