# 评测运行简明教程（三步跑通）

> 目标：测一份文档的知识抽取准确率。全程在 `backend` 目录下执行，Python 用项目虚拟环境 `../../.venv/Scripts/python.exe`（下文简写为 `python`）。
>
> 前提：该文档的抽取结果 `xxx_extraction.json` 已存在（批量生成过），金标准 `gold_xxx.json` 已人工标注好。

只需要记住 3 步，每步换一个词：**文件名**。

---

## 第 1 步：包装 pred（把抽取结果转成评测格式）

把下面命令里的 `数据结构第一章` 换成你要测的文件名，运行一次：

```bash
cd backend
../../.venv/Scripts/python.exe -X utf8 -c "
import json
from pathlib import Path
stem = '数据结构第一章'
raw = json.loads(Path(f'data/sample_docs/数据结构tree/{stem}_extraction.json').read_text(encoding='utf-8'))
wrapped = [{'text_id': stem, 'entities': raw['entities'], 'relations': raw['relations']}]
Path(f'eval_data/pred_{stem}.json').write_text(json.dumps(wrapped, ensure_ascii=False, indent=2), encoding='utf-8')
"
```

注意：第 4 行的路径要写成抽取结果实际所在的位置。文件在哪个子目录就写哪个，比如数据结构章节是 `data/sample_docs/数据结构/...`，化学的章节是 `data/sample_docs/openstax_化学/...`。

## 第 2 步：跑评测

同样只换文件名：

```bash
../../.venv/Scripts/python.exe eval_accuracy.py \
    --gold eval_data/gold_数据结构第一章.json \
    --pred eval_data/pred_数据结构第一章.json \
    --output eval_data/eval_report_数据结构第一章.json \
    --markdown eval_data/评测报告_数据结构第一章.md
```

## 第 3 步：看结果

跑完看三个地方：

- **终端直接打印** P / R / F1
- **`eval_data/评测报告_xxx.md`** —— Markdown 报告（要交的材料）
- **`eval_data/eval_report_xxx.json`** —— 完整数据

**只看一个数**：`[关系-主指标 relation_primary ← 赛题申报口径]` 的 F1，赛题要求 **≥ 0.70**。

---

## 常见问题

| 报错/现象 | 原因 | 解决 |
|-----------|------|------|
| F1 全是 0 | gold 和 pred 的 `text_id` 没对上 | 两边的 `text_id` 必须一字不差 |
| `Gold 必须是 list` | gold 文件最外层不是 `[...]` | 照抄 `gold_数据结构第一章.json` 的结构 |
| 找不到 pred 文件 | 第 1 步路径写错 | 确认 `xxx_extraction.json` 实际在哪个子目录 |

## 批量测 46 份

第 2 步的评测命令不含中文引号嵌套问题，可以写进 `.sh` 或 `.bat` 循环；第 1 步的包装逻辑也可以批量做。需要时让我写个一键脚本即可。
