##3.2 格式化字符串（Formatted strings）

10. 以下代码的输出是什么？
    ```python
    animal = "dog"
    says = "bark"
    print(f"My {animal} says {says} {says} {says}")
    ```
    a. My dog bark bark bark bark
    b. My dog says bark bark bark
    c. Error
11. 以下代码的输出是什么？
    ```python
    temp = "hot"
    food = "soup"
    print(f"This {temp} {food} is {temp}!")
    ```
    a. This hot soup is hot!
    b. This {temp} {food} is {temp}!
    c. Error
12. 如何使用 f-string 重写以下代码？
    ```python
    print(x, "+", y, "=", x + y)
    ```
    a. print(f"x+y={x+y}")
    b. print(f"{x}+{y}={x+y}")
    c. print(f"{x}+{y}={x+y}")
13. 哪个 f-string 将日期格式化为 MM/DD/YYYY？
    a. f"{month:02d}/{day:02d}/{year}"
    b. f"{month:2d}/{day:2d}/{year}"
    c. f"{month}/{day}/{year}"
14. 哪个语句将变量 money 显示为四舍五入到两位小数？
    a. print(f"{money:2d}")
    b. print(f"{money:2f}")
    c. print(f"{money:.2f}")
15. 哪个格式说明符将浮点数显示为带逗号分隔符并四舍五入到两位小数？
    a. .2,f
    b. .2f
    c. .d.2f

##3.4 列表基础（List basics）

22. 创建数字 3、4 和 5 的列表的正确方法是什么？
    a. new_list == [3, 4, 5]
    b. new_list = [3, 4, 5]
    c. new_list == (3, 4, 5)
23. 以下哪项不是在 Python 中指定列表的有效方式？
    a. my_list = [2, 2 3, 23]
    b. my_list = ["Jimmy", 2, "times"]
    c. my_list = ["C", "C++", "Python", "Java", "Rust", "Scala"]
24. 访问名为 cardList 的列表中第 17 个元素的正确方法是什么？
    a. card_list[17]
    b. card_list(16)
    c. card_list[16]
25. 在以下列表中将元素 "Tom" 修改为 "Tim" 的正确方法是什么？
    ```python
    name_list = ["Carla", "Monique", "Westin", "Tom"]
    ```
    a. name_list[-1] = "Tim"
    b. name_list[4] = "Tim"
    c. name_list[end] = "Tim"
