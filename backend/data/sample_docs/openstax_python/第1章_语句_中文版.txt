##基本输出

print() 函数向用户显示输出。输出是程序产生的信息或结果。sep 和 end 选项可用于自定义输出。表 1.1 显示了 sep 和 end 的示例。
多个值可以用逗号分隔，在同一条语句中打印。默认情况下，每个值在输出中用空格字符分隔。sep 选项可用于更改此行为。
默认情况下，print() 函数在输出末尾添加换行符。换行符告诉显示器移到下一行。end 选项可用于在同一行继续打印。

表 1.1 print() 的示例用法

##代码 输出
print("Today is Monday.") print("I like string beans.") Today is Monday. I like string beans.
print("Today", "is", "Monday") print("Today", "is", "Monday", sep="...") Today is Monday Today...is...Monday
print("Today is Monday", end=" ") print("I like string beans.") Today is Monday I like string beans.
print("Today", "is", "Monday", sep="?", end="!") print("I like string beans.") Today?is?Monday!! I like string beans.

##赋值语句

变量允许程序使用名称而不是内存位置来引用值。例如：age 指一个人的年龄，birth 指一个人的出生日期。

语句可以使用赋值运算符（=）将变量设置为某个值。注意这与数学中的等号不同。例如：age = 6 或 birth = "May 15"。赋值语句的左侧是变量，右侧是赋给变量的值。

##变量命名规则

变量名可以由字母、数字和下划线组成，长度不限。名称不能以数字开头。例如：101class 无效。此外，字母大小写很重要。例如：Total 与 total 不同。Python 的风格指南建议使用 snake case 编写变量名，即全小写，单词之间用下划线分隔，例如 first_name 或 total_price。

名称应该简短且具有描述性，因此在程序中，单词比单个字符更受青睐，以提高可读性。例如：名为 count 的变量比名为 c 的变量更能表明变量的用途。

Python 有保留字，称为关键字，它们具有特殊功能，不能用作变量（或其他对象）的名称。


##运算符优先级

当计算中有多个运算符时，每个运算符按优先级顺序求值。例如：1 + 2 * 3 是 7，因为乘法优先于加法。然而，(1 + 2) * 3 是 9，因为括号优先于乘法。

表 1.4 运算符优先级（从高到低）

运算符 描述 示例 结果
() 括号 (1 + 2) * 3 9
** 幂运算 2 ** 4 16
+, - 正、负 -math.pi -3.14159
*, / 乘法、除法 2 * 3 6
+, - 加法、减法 1 + 2 3

#如何阅读错误

犯错误是编程的自然组成部分。即使是经验丰富的程序员在编写代码时也会犯错误。编写代码时犯错误可能会导致错误。计算机需要非常具体的指令来告诉它该做什么。如果指令不清楚，计算机就不知道该怎么办，并返回错误。

当发生错误时，Python 显示一条包含以下信息的信息：
错误的行号。
错误类型（例如：SyntaxError）。
关于错误的额外细节。

例如：输入 print "Hello!" 而没有括号是语法错误。在 Python 中，使用 print 需要括号。当尝试运行 print "Hello!" 时，Python 显示以下错误：
```

Traceback (most recent call last):

 File "/home/student/Desktop/example.py", line 1

   print "Hello"

         ^

SyntaxError: Missing parentheses in call to 'print'. Did you mean print("Hello")?

```

插入符字符（^）显示 Python 发现错误的位置。有时错误可能位于插入符符号所示位置的前一两行，因为 Python 可能直到那时才发现错误。Traceback 是 Python 对错误位置和类型的报告。traceback 这个词建议程序员在代码中回溯以找到错误，如果错误没有立即看到的话。

仔细阅读错误信息是一项重要技能。技术术语的数量一开始可能让人不知所措。但这些信息非常有用。

##井号字符



注释是解释代码在做什么的简短短语。例如：以下程序中的第 1、8 和 10 行包含注释。每个注释以井号字符（#）开头。从井号字符到行末的所有文本在运行程序时都被忽略。相反，字符串内的井号字符被视为常规文本。例如：字符串 "Item #1: " 不包含注释。



编写注释时：



· # 字符后应跟一个空格。例如：# End of menu 比 #End of menu 更易读。

· 注释应解释代码的目的，而不仅仅是重复代码本身。例如：# Get the user's preferences 比 # Input item1 and item2 更具描述性。

##1.8 为什么选择 Python？(Why Python?)
学习目标

在本节结束时，你应该能够：

· 描述 Python 被认为是流行语言的两种方式。

##历史背景

Python 有一段有趣的历史。1982 年，Python 的创造者 Guido van Rossum 开始在一家荷兰国家研究机构 CWI 工作。他加入了一个团队，该团队正在设计一种新的编程语言，名为 ABC，用于教学和原型设计。ABC 的简单性非常适合初学者，但该语言缺乏编写高级程序所需的功能。

几年后，van Rossum 加入了 CWI 的另一个团队，从事操作系统工作。该团队需要一种更简单的方法来编写用于监控计算机和分析数据的程序。20 世纪 80 年代常见的语言（现在仍然如此）很难用于这类程序。van Rossum 设想了一种新语言，它具有像 ABC 一样简单的语法，但也提供专业人士需要的高级功能。

起初，van Rossum 将这种新语言作为业余爱好在空闲时间开发。他将该语言命名为 Python，因为他是英国喜剧团体 Monty Python 的粉丝。在接下来的一年里，他和同事成功地多次将 Python 用于实际工作。van Rossum 最终决定在网上与更广泛的编程社区分享 Python。他免费分享了 Python 的整个源代码，以便任何人都可以编写和运行 Python 程序。

Python 的第一个版本，称为 Version 0.9.0，出现在 1991 年，比 C++ 晚约六年，比 Java 早四年。van Rossum 决定使该语言简单而高级、适合日常任务并在网上免费提供，这些决定促成了 Python 的长期成功。
