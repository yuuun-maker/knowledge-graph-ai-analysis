##引言

计算机程序是一系列一个接一个运行的语句。在 Python 中，许多语句由一个或多个表达式组成。表达式表示要计算的单个值。例如：当 x 为 4 时，表达式 3 * x - 5 求值为 7。学会识别表达式为编写各种有趣的计算程序打开了大门。

表达式通常是字面量、变量和运算符的组合。在上面的例子中，3 和 5 是字面量，x 是变量，* 和 - 是运算符。表达式可以任意长，由许多计算组成。表达式也可以短到一个值。例如：在赋值语句 x = 5 中，字面量 5 就是一个表达式。

Statements 章节介绍了像 1 * 2 和 "Hi " + "there" 这样的简单表达式。本章探讨用于处理数字和字符串的其他类型的表达式。第一节展示了使用 Python shell 试验表达式的好方法。后面的小节介绍有关整数和浮点数的更多细节，解释如何导入和使用 math 模块，并展示如何使长代码行更易读。

##解释器

Python 是一种高级语言，这意味着源代码是供人类理解的。另一方面，计算机只理解由 1 和 0 组成的低级机器码。用高级语言编写的程序必须翻译成机器码才能运行。这个翻译过程可以一次全部发生，也可以根据语言的不同一次发生一点。

Python 是一种解释型语言：源代码在程序运行时逐行翻译。Python 解释器将源代码翻译成机器码并运行生成的程序。如果发生错误，解释器停止翻译源代码并显示错误信息。

大多数开发环境都包含一个 Python shell，用于交互式地试验代码。Shell，也称为控制台或终端，是一种允许直接与解释器交互的程序。解释器通常一次运行整个程序。但在 Python shell 中，解释器可以一次运行一行代码。

##隐式类型转换

常见操作会更新变量，使得变量的数据类型需要更改。例如：GPS 首先将 distance 赋值为 250，一个整数。在走错路后，GPS 将 distance 赋值为 252.5，一个浮点数。Python 解释器使用隐式类型转换自动将一种数据类型转换为另一种。一旦 distance 被赋值为 252.5，解释器将 distance 从整数转换为浮点数，而不需要程序员指定转换。

##显式类型转换

程序员经常需要更改数据类型以执行操作。例如：程序应使用 input() 读取两个值并对这些值求和。记住 input() 将值作为字符串读取。程序员可以使用显式类型转换将一种数据类型转换为另一种。

· int() 将数据类型转换为整数。任何小数部分都被移除。例如：int(5.9) 产生 5。
· float() 将数据类型转换为浮点数。例如：float(2) 产生 2.0。
· str() 将数据类型转换为字符串。例如：str(3.14) 产生 "3.14"。

##组合整数和浮点数

程序员经常需要组合不同数据类型的数字。例如：程序计算在线购物订单的总价：

```python
quantity = int(input())
price = float(input())
total = quantity * price
print(total)
```

quantity 是整数，price 是浮点数。那么 total 的数据类型是什么？对于输入 3 和 5.0，total 是浮点数，程序打印 15.0。

组合整数和浮点数产生浮点数。浮点数默认打印时小数点后至少有一位数字，并根据需要有多位数字来表示该值。注意：使用 / 运算符的除法总是产生浮点数。

##2.4 浮点错误(Floating-point errors )

学习目标

在本节结束时，你应该能够：

· 解释与浮点表示相关的数值不准确。
· 使用 round() 函数减轻输出中的浮点错误。

##浮点错误

计算机使用 0 和 1 存储信息。所有信息都必须转换为 0 和 1 的字符串。例如：5 被转换为 101。由于只允许两个值 0 或 1，该格式称为二进制。

浮点值由 Python 以二进制存储。将浮点数转换为底层二进制会导致特定类型的浮点错误。

舍入误差发生在浮点值被错误地存储为近似值时。计算中使用的值的近似值与正确（真实）值之间的差称为舍入误差。

例如：存储浮点数 (0.1)₁₀ 会导致二进制值，转换回来时实际上产生 (0.100000000000000055511151231257827021181583404541015625)₁₀，这不完全等于 (0.1)₁₀。

```python
# 打印带 30 位小数的浮点数
print(f'{0.1:.30f}')  # 打印 0.1
print(f'{0.2:.30f}')  # 打印 0.2
print(f'{0.4:.30f}')  # 打印 0.4
```

输出：

```
0.10000000000000005551115123126
0.200000000000000011102230246252
0.400000000000000022204460492503
```

溢出错误发生在值太大而无法存储时。可以表示的最大和最小浮点值分别为 1.8 × 10³⁰⁸ 和 -1.8 × 10³⁰⁸。尝试存储超出范围 (-1.8 × 10³⁰⁸, 1.8 × 10³⁰⁸) 的浮点值会导致溢出错误。

下面，3.0 ** 256 和 3.0 ** 512 可以表示，但 3.0 ** 1024 太大并导致溢出错误。

```python
print('3.0 to the power of 256 =', 3.0**256)
print('3.0 to the power of 512 =', 3.0**512)
print('3.0 to the power of 1024 =', 3.0**1024)
```

输出：

```
3.0 to the power of 256 = 1.3900845237714473e+122
3.0 to the power of 512 = 1.9323349832288915e+244
3.0 to the power of 1024 =
Traceback (most recent call last):
  File "<stdin>", line 3, in <module>
OverflowError: (34, 'Numerical result out of range')
```

##2.5 整数除法(Dividing integers)

学习目标

在本节结束时，你应该能够：

· 求值涉及向下取整除法和取模的表达式。
· 使用取模运算符在度量单位之间转换。

##除法和取模

Python 提供了两种除以数字的方法：

· 真除法（/）在除法前将数字转换为浮点数。例如：7 / 4 变成 7.0 / 4.0，结果为 1.75。
· 向下取整除法（//）计算商，即除的次数。例如：7 // 4 是 1，因为 4 进入 7 一次，余数为 3。取模运算符（%）计算余数。例如：7 % 4 是 3。

注意：% 运算符传统上发音为 "mod"（modulo 的缩写）。例如：当大声读 7 % 4 时，程序员会说 "seven mod four"。

##单位转换

除法可用于将一种度量单位转换为另一种。要将厘米转换为米，变量除以 100。例如：300 厘米除以 100 是 3 米。

数量作为整数通常不能均匀除尽。193 厘米是 1.93 米，或 1 米 93 厘米。程序可以使用向下取整除法和取模来分离单位：

· 商，1 米，是 193 // 100。
· 余数，93 厘米，是 193 % 100。

程序经常一起使用向下取整除法和取模。如果一行代码向下取整除以 m，下一行很可能对 m 取模。用于除某个量的单位 m 称为模数。例如：将厘米转换为米时，模数是 100。

##推荐的间距

Python 代码中的大多数空格在运行程序时被忽略；然而，行首的空格非常重要。以下两个程序是等价的：

良好间距：

```python
name = input("Enter someone's name:")
place = input("Enter a famous place:")
print(name, "should visit", place + "!")
```

差间距：

```python
name=input("Enter someone's name:")
place=input("Enter a famous place:")
print(name,"should visit",place+"!")
```

有人可能会说，缺少或多余的空格无关紧要。毕竟，上面两个程序运行方式完全相同。然而，"差间距"版本更难阅读。像 name=input 和 place+"!" 这样的代码可能会导致混淆。

优秀的程序员编写的代码尽可能易读。这样，其他程序员更有可能理解代码。为了鼓励一致性，Python 社区有一套关于在哪里放置空格和空行、如何命名变量、如何分解长行以及其他重要主题的指南。

##PYTHON 风格指南

PEP 8 是 Python 的官方风格指南。PEP 代表 Python Enhancement Proposal。Python 社区的成员编写 PEP 来记录最佳实践并提出新功能。下表基于 PEP 8 中 "Whitespace in Expressions and Statements" 标题下的指南。

表 2.7 空格指南

指南 示例 常见错误
括号：前后无空格。 print("Go team!") print( "Go team!" )
逗号：前无空格，后一个空格。 print("Hello", name) print("Hello",name)
