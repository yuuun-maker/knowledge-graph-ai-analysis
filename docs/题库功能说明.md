# 题库功能说明（教师组题 + 学生练题）

> 交付物对应「教师端题库管理」与「学生端做题练习」。本文说明题型范围、判分口径、答案下发时机、作用域规则，以及与图谱/学习路径的联动方式。
> 实现位置：`backend/app/services/question_service.py`（业务）、`backend/app/api/questions.py`（教师端）、`backend/app/api/practice.py`（学生端）、`frontend-vue/src/views/TeacherView.vue`（题库管理 Tab）、`frontend-vue/src/views/StudentView.vue`（做题练习 Tab）。

---

## 一、题型范围（Scope A）

| 题型 | 代码 | 判分方式 | 存储 |
|------|------|----------|------|
| 单选题 | `SINGLE` | 选项键归一化后严格相等 | `options` = `[{key,text}]` JSON；`answer` = `"A"` |
| 多选题 | `MULTI` | 选项键**集合**严格相等（顺序无关，少选/多选均判错） | `answer` = `["A","C"]` |
| 判断题 | `JUDGE` | 布尔归一化后相等（`对/正确/是/true/T/1` 等价） | `answer` = `"true"` / `"false"` |

**暂不支持**：填空题、简答题（需要答案归一化策略或 LLM 评分，准确性无法保证，故不纳入第一版；表结构已预留 `q_type` 白名单扩展位）。

`options` / `answer` 一律以 **JSON 文本**入库（`json.dumps` 序列化），理由：SQLite 无数组类型；且若对字符串直接原样入库，单选答案 `"A"` 回读时 `json.loads` 会失败、判断答案 `"true"` 会被误读成布尔值，导致「单选题永远判错」——该缺陷在开发期被 `test_question_bank.py` 捕获并修复（见 `SQLDatabase._json_text` 注释）。

## 二、防泄题：答案解析的下发时机

```
出题 GET /api/v1/practice/questions
    └── 走 _public_view() 白名单投影
        → 只返回 question_id / q_type / q_type_label / stem / options / difficulty / kp_id / is_favorited
        → 绝不包含 answer / analysis

提交 POST /api/v1/practice/submit
    └── 服务端判分 → 写 t_answer_record → 才返回 {is_correct, score, correct_answer, analysis}
```

- 出题与「我的收藏」列表都走同一白名单函数，避免新增端点时漏删字段。
- 学生答题记录接口（本人已作答）会返回正确答案，用于回看复习，属预期行为。
- 教师端（`/api/v1/questions`）返回完整答案与解析，且每个方法都做「课程归属校验」（非本课程教师 → `code 4003`）。

## 三、题目作用域

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `course_id` | ✅ | 题目归属课程，三端统一整数 |
| `document_id` | ⬜ | 留空 = **课程通用题**；填写 = 挂到具体文档（校验该文档属于该课程） |
| `kp_id` | ⬜ | 逻辑外键 → Neo4j `KnowledgePoint`，用于「推荐知识点 → 直接练题」 |

出题查询规则：`WHERE course_id = ? AND is_active = 1 AND (document_id = ? OR document_id IS NULL)`
—— 即「本学习资料」范围会同时取到该文档题与课程通用题；选择「整门课程」则不再限制文档。

**文档删除**只清理该文档精确挂载的题目与作答记录，**课程通用题刻意保留**（`delete_questions_by_document` 仅匹配 `document_id = ?`）。

## 四、教师端能力（题库管理 Tab）

| 功能 | 说明 |
|------|------|
| 新增 / 编辑题目 | 题干、题型、动态选项（2–8 个，不重排编号以免答案键错位）、正确答案、解析、难度（1–5）、所属文档、关联知识点（下拉取自当前文档图谱节点） |
| 题库总览 | 题目总数 / 启用中 / 三种题型数量 / 累计作答 / 平均正确率 / 被收藏数 |
| 列表与筛选 | 文档（含课程通用题）、题型、启用状态、题干关键词、分页 |
| 每题统计 | 作答人次、正确率、被收藏数（列表列内直接可见） |
| 题目收藏情况 | 抽屉展示「哪些学生收藏了哪道题」（学生姓名 / 用户名 / 收藏时间） |
| 启用 / 停用 | 停用 = 从出题池移除，**保留**历史答题记录 |
| 删除 | 已被学生作答过的题目自动降级为**软删（停用）**，避免删除学生作答数据；未作答过的题目物理删除 |

## 五、学生端能力（做题练习 Tab）

| 功能 | 说明 |
|------|------|
| 练习设置 | 出题范围（本学习资料 / 整门课程）、题型、知识点、数量（5/10/20） |
| 按推荐知识点出题 | 读取已掌握知识点 → 调用 `learning-path/recommend` → 用推荐的知识点作为出题过滤条件（**推荐 → 练题闭环**） |
| 答题卡 | 单选 / 多选 / 判断按题型渲染；提交后展示✅/❌、正确答案、解析，并禁止再改答案 |
| 我的练习统计 | 累计作答 / 正确率 / 错题数 / 收藏题目数 |
| 错题本 | 按题去重，取**每题最近一次答错**，含错答次数、最近错误作答、正确答案、解析、关联知识点；支持「重做」 |
| 收藏题目 | 收藏 / 取消收藏（幂等）；收藏列表可直接重做 |
| 查看知识点 | 跳转「图谱浏览」并打开知识点详情抽屉（复用 `locateKnowledgePoint`） |

## 六、与既有模块的联动与边界

1. **与学习记录**：答题**不自动**写入 `t_learning_record`（避免"刷题"污染学习进度口径与既有测试报告数据）。学生如需标记掌握，请在图谱浏览/详情中使用「标记已掌握」。
2. **与图谱**：题目通过 `kp_id` 关联知识点；题目本身不写入 Neo4j，图模型零改动。
3. **与学习路径**：学生端「按推荐知识点出题」读取推荐结果；教师端教学监测仍按课程级汇总（未把刷题数据混入进度统计）。
4. **与选课体系**：系统当前无选课关系表，学生可见课程内全部启用题目（与文档、图谱的可见性口径一致）。若后续引入班级/选课，只需收紧 `PracticeService.get_questions` 的课程可见性判断。

## 八、已知限制

1. 不支持填空题 / 简答题（见第一节）。
2. 判断题/选择题仅按选项键判分，尚未支持「选项内容级」同义匹配。
3. 教师端暂不支持批量导入（Excel/CSV）与「AI 自动出题」（表已预留 `source` 字段：`MANUAL / AI / IMPORT`）。
4. 错题本口径为「曾经答错即保留」，不随答对自动移除（便于复习巩固；如需自动移除，可在 `PracticeService.wrong_book` 增加"最近一次作答为正确则跳过"的判定）。
