##= 与 ==

一个常见错误是使用 = 进行比较而不是 ==。例如：is_zero = num = 0 总是将 is_zero 和 num 赋值为 0，无论 num 的原始值是什么。= 运算符执行赋值并修改变量。== 运算符执行比较，不修改变量，并产生 True 或 False。

##if 语句

如果天气下雨，拿把伞！人们根据像天气下雨这样的条件做出决定，程序根据像变量值这样的条件执行操作。例如：程序将两个数字相加。如果结果是负数，程序打印错误。

条件是求值为真或假的表达式。if 语句是一种决策结构，包含条件和语句体。如果条件为真，则执行语句体。如果条件为假，则不执行语句体。

if 语句的语句体必须分组在一起，并有一级缩进。PEP 8 风格指南建议每级缩进四个空格。如果语句体为空，Python 解释器将产生错误。

##if-else 语句

if 语句定义条件为真时要执行的操作。如果只需要在条件为假时执行操作呢？例如：如果餐厅不到一英里远，我们走路。否则，我们开车。

else 语句与 if 语句一起使用，包含一组语句，当 if 语句的条件为假时执行。当执行 if-else 语句时，只采用其中一个分支。也就是说，执行 if 的语句体或 else 的语句体。注意：else 语句与 if 语句在同一缩进级别，语句体缩进。

if-else 语句模板：

```python
# 前面的语句
if condition:
    # 语句体
else:
    # 语句体

# 后面的语句
```

##4.4 运算符优先级(Operator precedence)

学习目标

在本节结束时，你应该能够：

· 描述结合性如何影响运算顺序。

##优先级

当表达式有多个运算符时，哪个运算符先求值？优先级规则提供运算符的优先级。优先级最高的运算符先执行。例如：1 + 2 * 3 是 7，因为乘法优先于加法。然而，(1 + 2) * 3 是 9，因为括号优先于乘法。

表 4.4 运算符优先级（从高到低）

运算符 含义
() 括号
** 幂运算（右结合）
*, /, //, % 乘法、除法、向下取整除法、取模
+, - 加法、减法
<, <=, >, >=, ==, != 比较运算符
not 逻辑非运算符
and 逻辑与运算符
or 逻辑或运算符

##结合性

如果相邻的运算符具有相同的优先级级别呢？结合性决定优先级相同时的运算顺序。例如：8 / 4 * 3 求值为 (8 / 4) * 3 而不是 8 / (4 * 3)，因为乘法和除法是左结合的。大多数运算符是左结合的，从左到右求值。幂运算是主要例外（如上所述），是右结合的：即从右到左求值。例如：2 ** 3 ** 4 求值为 2 ** (3 ** 4)。

当比较运算符被链接时，表达式转换为比较的等价组合，并从左到右求值。例如：10 < x <= 20 求值为 10 < x and x <= 20。

##4.5 链式决策(Chained decisions)

学习目标

在本节结束时，你应该能够：

· 识别 if-elif 和 if-elif-else 语句中采用的分支。
· 创建链式决策语句以评估多个条件。

##elif

有时，复杂的决策基于不止一个条件。例如：旅行规划网站审查行程中的中转停留。如果中转停留超过 24 小时，网站应建议住宿。否则，如果中转停留少于一小时，网站应警告可能错过转机。

两个单独的 if 语句不保证只采用一个分支，可能导致两个分支都被采用。例如：下面的程序尝试根据输入的考试分数添加曲线。如果输入是 60，两个 if 语句都被错误执行，最终分数是 75。

```python
score = int(input())
if score < 70:
    score += 10  # 错误
if 70 <= score < 85:
    score += 5
```

用 elif 链接决策语句允许程序员检查多个条件。elif（else if 的缩写）语句在前一个决策语句的条件为假时检查条件。elif 语句是链的一部分，必须跟在 if（或 elif）语句之后。

##if-elif 语句模板：

```python
# 前面的语句

if condition:
    # 语句体
elif condition:
    # 语句体

# 后面的语句
```

##4.7 条件表达式(Conditional expressions)

学习目标

在本节结束时，你应该能够：

· 识别条件表达式的组成部分。
· 创建条件表达式。

##条件表达式

条件表达式（也称为"三元运算符"）是 if-else 语句的简化单行版本。

条件表达式模板：

```python
expression_if_true if condition else expression_if_false
```

条件表达式的求值方式是首先检查条件。如果条件为真，求值 expression_if_true，结果是条件表达式的结果值。否则，求值 expression_if_false，结果是条件表达式的结果值。

变量可以用条件表达式赋值。例如：求两个数字的最大值可以计算为 max_num = y if x < y else x。

注意：条件表达式的优先级在所有 Python 运算中最低。

##4.8 章节小结(Chapter summary)

本章的重点包括：

· 布尔值表示 True 或 False 的值。
· 比较运算符比较值并产生 True 或 False。
· 逻辑运算符接受条件操作数并产生 True 或 False。
· 运算符按优先级和结合性顺序求值。
· 条件是求值为 True 或 False 的表达式。
· 决策语句允许根据条件通过代码的不同执行路径（分支）。
· 决策语句可以嵌套在其他决策语句内部。
· 条件表达式是 if-else 语句的单行版本。

not x（逻辑） 求值 x 的布尔值，如果值为假则返回 True，如果值为真则返回 False。例如：not True 是 False。
